# PADE：基于正向注意力动态的视觉幻觉缓解方法

## 导读：从“注意力有多大”转向“注意力如何变化”

大型视觉语言模型（Large Vision-Language Models，LVLMs）虽然具备较强的图像理解、视觉问答与多模态推理能力，但仍容易生成与图像事实或用户指令不一致的内容，即产生视觉幻觉。本文所讨论的论文提出了一条不同于传统静态注意力增强的思路：与其直接选择某一层中注意力值最大的视觉区域，不如观察视觉注意力在不同 Transformer 层之间的演化过程，寻找那些随着模型逐层理解而反复获得更多关注的区域。

基于这一观察，论文提出 Positive Attention Dynamics Enhancement（PADE，正向注意力动态增强）。其完整逻辑是：先从相邻层的视觉注意力变化中提取 Positive Attention Dynamics（PAD），再通过 Median Absolute Deviation（MAD，中位数绝对偏差）将 PAD 调整到各注意力头的 logit 尺度，随后把缩放后的 PAD 注入目标层的视觉注意力 logits，并从系统 token 的注意力 logits 中释放一部分注意力预算，以尽量保护用户指令和历史输出。最终，PADE通过改变目标层的注意力分布、隐藏状态及输出词概率，提高模型对真实视觉证据的依赖。

# 1. 该篇论文尝试解决什么问题？

## 1.1 核心问题：LVLM 的输出可能脱离真实视觉证据

论文关注的是大型视觉语言模型中的视觉幻觉问题。视觉幻觉不仅包括“描述了图中不存在的物体”，也包括更广泛的不一致现象，例如：

- 将不存在的杯子、手机或包判断为存在；
- 将图中真实存在的小目标或遮挡目标判断为不存在；
- 错误描述物体的颜色、方向、数量或空间关系；
- 在长文本生成中逐渐偏离图像内容；
- 忽略用户问题中的约束，转而依据常见语言模式作答。

这类问题的本质，是模型在生成答案时没有充分依赖与当前问题相关的视觉证据，而是受到语言先验、模板结构或无关内部激活的影响。换言之，模型“能够看到图像”并不代表它在最终决策时仍然有效利用了图像。

## 1.2 视觉幻觉为何会发生：语言先验、视觉利用不足与注意力汇聚

论文将视觉幻觉的重要原因概括为三个相互关联的方面。

第一，模型可能过度依赖语言先验。例如在室内场景中，“桌子旁通常有杯子”是一种常见统计关联。即使当前图像中没有杯子，模型也可能依据语言共现关系给出肯定回答。

第二，视觉信息在多层推理和生成过程中可能被逐渐削弱。模型在某些中间层已经关注到正确对象，但在后续层中，注意力又扩散至其他区域或被文本结构主导，导致正确视觉证据没有充分进入最终输出决策。

第三，模型内部存在 attention sink，即少量 token 长期吸收不成比例的注意力。attention sink 的注意力值可能很高，但高注意力并不意味着它对当前图像问题具有同等强度的语义贡献。系统提示、模板 token、特殊 token 或某些孤立视觉位置都可能形成静态高值。如果依据绝对注意力值选择 Top-K 区域，就可能反复选择并放大这些 sink，进一步挤压真正有用的视觉区域。

需要注意的是，论文并未证明所有高注意力系统 token 都完全无用，也没有把 attention sink 等同于纯噪声。更准确的说法是：这些 token 的静态注意力数值与当前视觉任务的语义重要性并不总是一致，因此不能直接把“注意力最大”当作“视觉证据最核心”。

## 1.3 现有方法为什么不足以解决这一问题？

论文将现有幻觉缓解方法分为训练型方法和免训练方法。训练型方法通过数据清洗、视觉—语言对齐训练、指令微调、检索增强或强化学习改变模型参数，能够从训练阶段改善模型，但通常需要大量数据、算力和模型级适配。

论文重点讨论三类免训练方法。

### 1.3.1 对比解码：成本较高，扰动信号可能带来偏差

对比解码通常分别对原始图像和扰动图像进行推理，再比较两次推理得到的 logits 或注意力。其意图是分离视觉证据与语言先验，但这类方法往往需要多次前向计算，而且模糊、加噪、遮挡等扰动并不只是“移除视觉信息”，还可能引入新的错误结构。因此，对比结果可能混合真实视觉贡献与扰动偏差。

### 1.3.2 外部专家模型：引入依赖，也可能与目标模型语义错位

另一类方法借助检测器、区域模型或验证器提供外部视觉线索。这虽然能够增强视觉依据，但会增加模型、显存和工程依赖。更重要的是，外部专家认为“显著”的对象未必与当前问题最相关。例如检测器可能优先识别一个大型瓶子，而用户真正询问的是旁边较小的杯子。

### 1.3.3 静态内部信号：容易把 attention sink 误认为语义核心

静态内部方法根据某层或某些注意力头的绝对注意力值、Top-K 排名或阈值选择视觉 token。它们隐含的假设是：当前注意力越大，token 越重要。但 attention sink 同样可能具有很高的静态值，因此这种选择可能进一步增强错误区域。

PADE由此提出一个更具体的问题：

> 在 attention sink 扭曲静态注意力分布的情况下，如何不依赖外部模型、不构造扰动输入、也不进行多次完整前向推理，可靠地识别并增强真正与当前任务相关的视觉区域？

## 1.4 论文的关键观察：动态变化比静态大小更能揭示语义核心

论文对 LLaVA-1.5 等模型的跨层注意力进行分析后发现，语义核心区域、无关背景和 attention sink 往往呈现不同的动态模式：

- 语义核心区域会在模型逐层理解过程中，多次出现明显的正向注意力增长；
- 无关背景通常长期维持低注意力，只发生微弱波动；
- attention sink 虽可能具有较大绝对值或偶发峰值，但其变化往往更加不规则，且不稳定对应当前视觉语义。

因此，论文不再问“哪个位置当前最亮”，而是问“哪个位置在多层推理过程中反复变得更重要”。这一观察构成 PADE 的方法基础。

# 2. 采用了什么样的方法解决该问题？

## 2.1 方法总览：PAD 提取、MAD 缩放、目标层注入与系统 token 补偿

PADE是一种训练无关的推理时注意力干预方法，主要由四个相互衔接的环节组成：

1. 从每一层的视觉注意力中提取正向跨层变化，构造 PAD 图；
2. 使用每个注意力头的 MAD 对 PAD 进行鲁棒尺度校准；
3. 将缩放后的 PAD 注入目标层的视觉 attention logits；
4. 从系统 token 的 attention logits 中减去补偿量，减轻视觉增强对指令和历史上下文的挤压。

在理解公式前，需要先区分三个变量：

- \(Z\)：softmax 之前的 attention logits，是尚未归一化的注意力分数；
- \(A=\operatorname{softmax}(Z)\)：softmax 之后的注意力权重；
- \(P\)：由多层注意力 \(A\) 的正向变化构成的 PAD 图。

PADE是“从 \(A\) 中发现区域，再回到 \(Z\) 上实施干预”。

## 2.2 从图像到视觉注意力图

### 2.2.1 图像被表示为视觉 token

图像首先经过视觉编码器，被划分或映射为一组视觉 patch 特征，再通过投影模块转换为语言模型可处理的视觉 token：

\[
v_1,v_2,\ldots,v_{N_v}.
\]

这些视觉 token 与系统提示、用户指令和历史输出共同组成多模态序列，可以抽象表示为：

\[
[\text{System}\mid\text{Vision}\mid\text{Instruction}\mid\text{Output}].
\]

每个视觉 token 通常对应图像中的一个局部 patch，因此后续对这些 token 的注意力可以重新排列成二维热力图。

### 2.2.2 从注意力 logits 得到注意力权重

在第 \(l\) 层、第 \(h\) 个注意力头中，标准缩放点积注意力首先计算：

\[
Z_{l,h}=\frac{Q_{l,h}K_{l,h}^{\top}}{\sqrt d},
\]

再通过 softmax 得到注意力权重：

\[
A_{l,h}=\operatorname{softmax}(Z_{l,h}).
\]

在自回归生成中，当前生成位置作为 query，对此前的系统、视觉、指令和历史输出 token 分配注意力。只截取视觉 token 所对应的部分，就得到当前注意力头的视觉注意力向量：

\[
A^{v}_{l,h}=\left[a_{l,h,1},a_{l,h,2},\ldots,a_{l,h,N_v}\right].
\]

其中，\(a_{l,h,j}\) 表示当前 query 对第 \(j\) 个视觉 token 的注意力。

### 2.2.3 在注意力头上求平均，形成视觉注意力图

论文将第 \(l\) 层的视觉注意力图定义为所有注意力头视觉注意力的平均：

\[
A_l=\frac{1}{H}\sum_{h=1}^{H}A^{v}_{l,h},
\]

其中 \(H\) 是注意力头数量。若视觉编码器产生的是 \(m\times n\) 个 patch，则长度为 \(N_v=mn\) 的向量 \(A_l\) 可以恢复为 \(m\times n\) 的二维网格并可视化为热力图。

**备注：**论文正文没有完全明确 query 维度的具体聚合方式，例如是否只取当前生成 token，或是否对多个输出 query 求平均。从自回归流程和附录逐 token 可视化来看，取当前生成位置对视觉 token 的注意力是较自然的解释，但精确复现仍需代码确认。

## 2.3 提取 Positive Attention Dynamics：从“静态值”转为“跨层增长”

有了不同层的视觉注意力图：

\[
A_1,A_2,\ldots,A_L,
\]

PADE先计算相邻层之间的正向注意力差分：

\[
\Delta^{+}A_l=\max\left(0,A_l-A_{l-1}\right),\qquad l=2,\ldots,L.
\]

其中 \(\max(0,\cdot)\) 对每个视觉位置逐元素执行。对第 \(j\) 个视觉 token 而言：

\[
\Delta^{+}A_l[j]=\max\left(0,A_l[j]-A_{l-1}[j]\right).
\]

若某个对象区域的注意力从 \(0.05\) 增加到 \(0.12\)，其正向变化为 \(0.07\)；若从 \(0.30\) 降至 \(0.08\)，则该层变化被截断为零。这样做的含义不是认为注意力下降完全无意义，而是专门提取“随着内部理解推进而变得更重要”的区域。

随后，将所有相邻层的正向差分求平均，得到 PAD 图：

\[
P=\frac{1}{L-1}\sum_{l=2}^{L}\Delta^{+}A_l.
\]

PAD对每个视觉位置累计其跨层正向增长。其直觉可归纳为：

- 核心对象不必在每层都拥有最高绝对注意力，但可能在多个阶段反复获得额外关注；
- 长期保持低值的背景区域很难积累较大的 PAD；
- 长期维持静态高值但变化较小的 sink 不会仅因绝对值高而被持续选中；
- 偶发尖峰仍可能进入 PAD，但跨层平均会在一定程度上降低单次异常的主导作用。

因此，PAD不是严格的 sink 检测器，也不能保证完全排除所有异常位置。它的优势是减少对静态幅值和 Top-K 排名的依赖，使跨层反复增长的区域更容易显现。

## 2.4 使用 MAD 对 PAD 进行逐头鲁棒缩放

### 2.4.1 为什么 PAD不能直接加到 logits 上？

PAD来自 softmax 后的注意力概率，通常数值较小；而最终需要修改的是 softmax 前的 logits，其尺度更大，且不同样本、不同注意力头之间存在明显差异。若直接执行：

\[
Z^v_{l,h}+\lambda P,
\]

PAD可能小到几乎无法改变 softmax 结果。反过来，如果使用固定的大倍数，又可能在某些注意力头上产生过强干预。

### 2.4.2 MAD从目标层的视觉 logits 中得到

对目标层 \(l\) 的第 \(h\) 个注意力头，取所有视觉 token 对应的 logits：

\[
Z^v_{l,h}=[z_1,z_2,\ldots,z_{N_v}].
\]

其 MAD 定义为：

\[
\operatorname{MAD}(Z^v_{l,h})=
\operatorname{median}\left(
\left|Z^v_{l,h}-\operatorname{median}(Z^v_{l,h})\right|
\right).
\]

MAD描述的是该注意力头中视觉 logits 的典型离散尺度。与标准差相比，MAD使用中位数，对 attention sink 引起的极端值更不敏感。例如 logits 为 \([-2,-1,0,1,20]\) 时，中位数为 \(0\)，绝对偏差为 \([2,1,0,1,20]\)，MAD仍为 \(1\)，不会被极端值 \(20\) 显著拉高。

### 2.4.3 MAD如何缩放 PAD？

论文将预处理或归一化后的 PAD 记为 \(\widetilde P\)，并进行逐头缩放：

\[
\widehat P_{l,h}=\operatorname{MAD}(Z^v_{l,h})\cdot\widetilde P.
\]

这一式子包含两个作用：

- \(\widetilde P\) 提供“哪些视觉位置应该被增强”的空间模式；
- \(\operatorname{MAD}(Z^v_{l,h})\) 提供“在当前注意力头中应该增强到什么尺度”的校准量。

因此，同一个 PAD 空间模式会在不同注意力头中获得不同的缩放强度，实现逐样本、逐头的自适应校准。

**复现备注：**论文先定义 \(P\)，随后在缩放公式中使用 \(\widetilde P\)，但正文未明确说明二者之间采用何种归一化或预处理，例如最大值归一化、min-max 归一化或范数归一化。这是论文中需要代码或作者补充才能完全确定的实现细节。

## 2.5 将缩放后的 PAD 注入目标层

缩放后，PADE在目标层的视觉 attention logits 上执行：

\[
\widehat Z^v_{l,h}=Z^v_{l,h}+\lambda\widehat P_{l,h},
\]

其中 \(\lambda\) 是全局干预强度。完整干预量可写为：

\[
\lambda\,\operatorname{MAD}(Z^v_{l,h})\,\widetilde P.
\]

由此可见，MAD和 \(\lambda\) 承担不同功能：MAD根据每个注意力头的内部尺度进行校准，\(\lambda\)则控制总体干预强弱。

论文实验显示，较小到中等强度通常更稳定，过小的 \(\lambda\) 无法明显改变 softmax，过大的 \(\lambda\) 则可能使注意力过度集中于局部区域、放大错误 PAD、挤压指令和历史上下文，并使隐藏状态偏离模型原始训练分布。论文采用 \(\lambda=0.1\) 作为有效默认值，但这不是理论上的固定最优值。

### 2.5.1 为什么通常在最后一层注入？

论文对不同目标层进行了比较，整体发现后层干预优于较早的候选层，最终层通常表现最好。作者的解释是：

- 中间层已经逐渐识别语义对象，为 PAD 提供了动态证据；
- 到后层时，视觉注意力可能向非核心区域扩散，或受到语言与上下文模式影响；
- 在最终层注入累计 PAD，相当于在输出头之前重新强调此前层中已经出现的核心视觉证据。

因此，最终层干预不是重新开展完整视觉理解，而是进行接近输出端的温和校正。论文没有系统验证所有层联合注入，也没有证明所有任务的最佳层都必然是最终层。未来仍可根据问题类型和动态信号自适应选择层。

## 2.6 System-Token Compensation：从系统 token 中释放注意力预算

### 2.6.1 系统 token 指什么？

系统 token 是由系统提示、聊天模板、角色标记、分隔符及部分特殊格式 token 形成的序列。例如论文图示中的系统提示包含“A chat between a curious user and an artificial intelligence assistant ...”。根据不同模型的 chat template，系统 token 的具体范围会有所不同。

论文将注意力池中的 logits 分成：

\[
[Z^s,Z^v,Z^i,Z^o],
\]

其中：

- \(Z^s\)：系统 token 的 attention logits；
- \(Z^v\)：视觉 token 的 attention logits；
- \(Z^i\)：用户指令 token 的 attention logits；
- \(Z^o\)：历史输出 token 的 attention logits。

原始注意力为：

\[
A=\operatorname{softmax}([Z^s,Z^v,Z^i,Z^o]).
\]

### 2.6.2 为什么视觉增强需要补偿？

softmax后的注意力总量固定为 \(1\)。若只提高视觉 logits，视觉 token 的注意力比例上升，其他 token 的比例就可能下降，其中包括用户指令和历史输出。这会影响复杂指令遵循、多轮上下文和长文本连贯性。

论文观察到系统 token 往往吸收较高注意力，但其与当前具体图像问题的直接语义相关性相对有限，因此选择系统 token 作为补偿来源，而不是直接降低指令或历史输出 logits。

### 2.6.3 STC如何降低系统 token 的 logits？

首先计算视觉增强量在视觉 token 维度上的平均值：

\[
c_{l,h}=\operatorname{mean}\left(\lambda\widehat P_{l,h}\right).
\]

随后从系统 token 的 logits 中减去该标量：

\[
\check Z^s=Z^s-c_{l,h}
=Z^s-\operatorname{mean}\left(\lambda\widehat P_{l,h}\right).
\]

该标量通常广播到对应注意力头中的所有系统 token。这里的“降低系统 token”不是删除系统提示、修改 token embedding 或更新模型参数，而只是在目标层、当前注意力计算中轻度降低当前 query 对系统 token 的未归一化注意力分数。

最终注意力分布为：

\[
\widehat A=
\operatorname{softmax}([
\check Z^s,
\widehat Z^v,
Z^i,
Z^o
]).
\]

STC并不能保证指令和历史 token 的最终 softmax 权重绝对不变，因为整个归一化分布已经改变。其更准确的作用是：不直接降低 \(Z^i\) 和 \(Z^o\)，并通过削弱部分系统 logits，减轻视觉增强对指令和历史注意力的挤压。

## 2.7 PADE如何影响最终生成？

PADE对输出的影响不是直接修改最终词表概率，而是沿着以下链路逐步传递：

\[
\text{视觉注意力变化}
\rightarrow P
\rightarrow \widehat P
\rightarrow \widehat Z^v,\check Z^s
\rightarrow \widehat A
\rightarrow \text{目标层隐藏状态}
\rightarrow \text{输出 logits}
\rightarrow \text{生成 token}.
\]

当 PAD集中于与问题相关的对象区域时，该区域在目标层中获得更高注意力，注意力加权后的特征随之改变，最终语言模型输出头会提高与真实视觉证据一致的词概率，并降低依赖语言先验的错误词概率。

## 2.8 PADE可以应用于哪些系统？

论文在 LLaVA-1.5、LLaVA-1.5-13B、LLaVA-NeXT、Qwen-VL 和 InstructBLIP 等开源 LVLM 上进行了验证。原则上，PADE更适合满足以下条件的系统：

1. 视觉信息以可定位的 token 形式进入多层 Transformer；
2. 可以访问各层 softmax 后的注意力权重；
3. 可以访问并修改目标层 softmax 前的 attention logits；
4. 可以区分系统、视觉、指令和历史输出 token 的索引范围；
5. 各层视觉 token 具有可比较的位置对应关系。

因此，本地部署、可修改 PyTorch forward 或 attention module 的开源模型最容易集成 PADE。只提供输入—输出接口的闭源 API 通常无法直接使用，因为无法读取或干预内部注意力。

对于视觉信息通过独立 cross-attention 注入的架构，PAD思想仍可用于视觉 cross-attention，但原始 STC不能直接照搬，因为视觉 token 与系统 token 可能不处于同一个 softmax 竞争池中。这类系统需要重新设计补偿机制。

## 2.9 实验结论如何支撑方法有效性？

论文在多种模型和多类幻觉基准上报告了一致改善，覆盖物体存在性判断、开放式图像描述、复杂视觉一致性与生成型幻觉。同时，通用视觉问答和多模态推理基准没有出现明显能力牺牲，部分任务还获得提升。这说明 PADE并非只通过让模型“少说话”或更保守来减少幻觉，而是在增强视觉 grounding 的同时较好地保留了通用能力。

消融实验进一步表明：去掉 MAD 后性能下降最明显，说明尺度校准是 PAD真正影响 logits 的关键；去掉 STC 后也会退化，说明上下文保护和注意力预算平衡具有实际作用。层与强度实验表明，后层尤其是最终层通常更适合干预，较小到中等的 \(\lambda\) 更稳定，而过强干预会破坏原始注意力结构。

论文将额外开销描述为较低，因为不需要辅助模型或第二次完整前向推理，只需维护注意力图、执行层间差分、MAD计算和目标层修改。不过正文缺少详细的 tokens/s、延迟、显存增量及 FlashAttention 兼容性数据，因此“开销可忽略”仍主要是定性结论。

# 3. 这篇论文的创新点是什么？

## 3.1 从静态注意力幅值转向跨层注意力动态

论文最核心的创新，是把视觉区域选择依据从“某一时刻的绝对注意力值”改为“跨层正向变化”。这一转变避免将静态高值直接等同于语义重要性，使模型内部理解过程中反复增强的区域成为视觉干预依据。

从方法论上看，它提出了一个更一般的观点：模型内部信号的演化轨迹，可能比单层快照更能揭示语义形成过程。

## 3.2 直接利用目标模型自身的内部证据

PADE不依赖目标检测器、外部专家、扰动图像、词性分析器或额外完整前向过程，而是从目标 LVLM 自身的注意力演化中提取核心视觉区域。这降低了外部依赖，也减少了辅助信号与目标模型内部语义不一致的风险。

与同样关注注意力变化的 GIFT 相比，PADE不要求从提示中提取明确关键词，因此更适用于“请详细描述图像”等缺乏显式对象词的通用指令；此外，PADE还增加了逐头 MAD 校准和 STC 上下文保护。

## 3.3 使用逐样本、逐注意力头的 MAD进行鲁棒尺度校准

PAD位于概率尺度，目标干预位于 logit 尺度，两者存在数量级和分布差异。PADE没有使用统一固定倍数，而是利用每个注意力头的 MAD估计其典型 logit 尺度。中位数统计对极端 sink 值更加鲁棒，使同一 PAD空间模式能够在不同样本和不同注意力头上获得适当强度。

这一设计把“区域识别”和“干预尺度”分离：PAD回答增强哪里，MAD回答增强多少。

## 3.4 提出系统 token 补偿，实现注意力预算的定向再分配

PADE不仅增加视觉注意力，还考虑 softmax竞争带来的副作用。STC选择从高注意力但对当前具体视觉语义贡献相对有限的系统 token 中释放一部分预算，而不直接降低用户指令和历史输出 logits。

因此，PADE不是单向放大视觉信号，而是在视觉 grounding、指令遵循和长程生成一致性之间进行有目的的注意力再平衡。

## 3.5 形成单次前向、免训练、接近输出端的轻量干预框架

PADE在目标层实施局部修改，不更新参数，也不依赖外部专家或多次完整推理。其作用位置接近最终输出，能够利用前面层已经形成的语义线索，又避免从早期层开始大范围改变模型内部计算。论文在不同模型架构和规模上的实验表明，该思路具有一定模型通用性。

## 3.6 从“降低幻觉”扩展为“保留通用能力的视觉校正”

一些幻觉缓解方法会通过更保守的生成降低错误，但同时削弱视觉覆盖或通用推理能力。PADE在论文测试中同时改善幻觉指标并保持通用多模态能力，说明其创新目标不仅是压低错误率，还包括使干预尽量与模型已有视觉理解过程保持一致。

# 4. 这篇论文有哪些未来可以继续创新的方法和方向？

以下方向分为两类：第一类是论文明确提出的扩展，第二类是根据其方法、实验和复现边界可以自然推导出的研究方向。

## 4.1 从注意力动态扩展到更多内部动态信号

这是论文在局限部分明确提出的方向。目前 PADE只分析跨层注意力变化，未来可以进一步建模：

- 隐藏状态的跨层变化；
- 前馈网络（FFN）的激活动态；
- 解码过程中输出 logits 的变化；
- 不同模态表示之间的动态对齐程度。

注意力更多表示模型“关注哪里”，隐藏状态和 FFN 激活可能反映“提取了什么语义”，输出 logits 动态则更接近“答案如何逐步形成”。将多种内部动态联合起来，可能比单一注意力信号更准确地识别幻觉风险。

## 4.2 自适应选择干预层和干预强度

当前方法通常采用最终层和固定 \(\lambda\)。未来可根据以下信号动态选择干预位置与幅度：

- PAD的集中度、熵或跨层稳定性；
- 图像复杂度和目标大小；
- 问题类型，如存在性、属性、计数或空间关系；
- 模型输出不确定度；
- 视觉注意力与语言注意力的比例；
- 当前生成阶段和历史长度。

例如，当 PAD高度集中且模型置信度较低时，可以增强干预；当 PAD分散、问题需要全局关系推理时，则应降低局部增强强度。还可以从固定单层注入扩展为稀疏多层或条件式多层注入。

## 4.3 从正向差分平均扩展为完整动态模式建模

当前 PAD只保留正向变化并对层求平均：

\[
P=\frac{1}{L-1}\sum_{l=2}^{L}\max(0,A_l-A_{l-1}).
\]

未来可以进一步研究：

- 正向和负向变化的联合建模；
- 连续多层增长与单层尖峰的区分；
- 注意力变化的一阶速度与二阶加速度；
- 不同层段的阶段性权重；
- 对 sink 的持续性、周期性和不规则性进行显式评分；
- 使用轻量时序模型学习跨层注意力轨迹。

这能进一步区分“持续形成的语义证据”和“偶发的异常波动”。

## 4.4 从 patch/token 级增强扩展到对象、属性和关系级证据

当前 PAD主要作用于视觉 patch token，空间粒度较粗。未来可以将相邻 patch 聚合为对象或区域，并结合：

- 目标边界或分割区域；
- 多尺度视觉特征；
- 小目标与遮挡对象检测；
- 对象属性、数量与空间关系图；
- 局部证据与全局场景证据的分层融合。

这样不仅能回答“图中是否有杯子”，还可更稳定地处理“杯子的颜色”“杯子在瓶子的哪一侧”以及“有几个杯子”等问题。

## 4.5 扩展到视频、多图、文档图像与视觉智能体

视频任务同时存在跨层动态和跨帧时间动态。可以联合建模：

- Transformer 层间注意力变化；
- 视频帧间对象轨迹变化；
- 动作与事件的时间一致性；
- 多图之间的实体对应；
- 文档页面与文本区域之间的证据链接。

在视觉智能体中，PAD还可用于判断下一步应该重新观察哪个区域、是否需要放大图像、调用工具或请求补充视觉输入。

## 4.6 建立 PAD与真实因果视觉证据之间的验证框架

论文主要通过热力图和最终性能说明 PAD更接近语义核心，但尚未充分证明高 PAD区域是答案形成的必要因果证据。未来可以采用：

- 遮挡或删除高 PAD区域；
- 仅保留高 PAD区域；
- 构造反事实图像；
- 比较人工目标框、分割掩码和 PAD区域；
- 测量 pointing game、IoU 或区域定位准确率；
- 分析干预后正确词与错误词 logits 的因果变化。

这能把“PAD与正确区域相关”进一步提升为“PAD对正确答案具有因果贡献”。

## 4.7 发展面向不同注意力架构的补偿机制

原始 STC依赖系统 token 与视觉 token 位于同一 softmax注意力池。对于独立 cross-attention、Perceiver resampler、Q-Former或更复杂的视觉—语言融合架构，需要重新定义注意力预算来源。未来可以探索：

- cross-attention中的总量约束；
- 对无关视觉 token 而非系统 token 进行补偿；
- 头级或层级预算守恒；
- 基于语义相关性的可学习补偿对象；
- 不依赖明确 system token 分区的通用补偿形式。

## 4.8 将推理时干预与训练方法结合

PADE可以与视觉指令微调、偏好优化、强化学习和检索增强结合。例如：

- 将高质量 PAD区域作为训练时视觉监督；
- 让模型学习预测何时需要启用 PADE；
- 用偏好优化奖励视觉证据一致的注意力动态；
- 在 PAD不稳定时触发检索、局部裁剪或二次视觉编码；
- 将 PAD用于自我校验或拒答机制。

这会把 PADE从固定推理插件扩展为训练—推理协同的视觉可靠性框架。

## 4.9 加强长文本、多轮对话和复杂指令验证

STC的设计目标之一是保护用户指令和历史输出，但论文主要以常规幻觉与多模态基准验证。未来需要专门测试：

- 长篇图像描述中的实体一致性；
- 多轮视觉问答中的对象与属性记忆；
- 长链视觉推理中间步骤的视觉依据；
- 生成后半段逐渐脱离图像的问题；
- 多约束指令中的条件保持。

还可以让补偿量随上下文长度和生成阶段动态变化，而不是始终使用同一形式。

## 4.10 完善实现细节与效率评测

论文仍有若干复现和证据边界需要进一步补足：

- 明确 \(P\rightarrow\widetilde P\) 的归一化流程；
- 明确视觉注意力图的 query 聚合方式；
- 给出不同模型中 system、vision、instruction、output token 的准确索引策略；
- 报告不同模型的速度、首 token 延迟、每 token 延迟和显存增量；
- 说明与 FlashAttention、KV cache 和批量推理的兼容方式；
- 提供多随机种子结果与统计显著性；
- 更系统地比较单层、多层和条件式注入。

这些工作既有助于提高 PADE的可复现性，也能明确其在真实部署中的成本和适用边界。

# 总结

该论文解决的不是一个简单的“增加视觉注意力”问题，而是一个更细致的视觉证据识别与注意力分配问题：静态高注意力可能受到 attention sink扭曲，因此不能直接代表语义核心；真正可靠的视觉区域，往往体现在模型逐层理解过程中反复出现的正向注意力变化。

PADE据此形成了完整的推理时干预链条：

\[
\boxed{
\text{跨层视觉注意力}
\rightarrow \text{PAD核心区域}
\rightarrow \text{MAD逐头校准}
\rightarrow \text{视觉 logits增强}
\rightarrow \text{系统 token补偿}
\rightarrow \text{更可靠的视觉生成}
}
\]

它的主要创新不仅在于提出三个具体组件，更在于建立了一种“利用内部信号动态而非静态快照进行模型干预”的方法论。未来，这一思想可以扩展到隐藏状态、FFN激活、输出 logits、视频时间动态和因果视觉证据，并与自适应控制、训练机制和复杂视觉系统结合，形成更通用的多模态可靠性框架。
